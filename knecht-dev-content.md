> Dieses Dokument enthält alle Texte, Strukturen und Inhalte für die Website knecht.dev.

## 8. FAQ

**Section-Headline:**
Häufige Fragen.

**F: Bist du wirklich allein?**
A: Ja. Wenn das Projekt zu groß für mich wird, sage ich das offen — und ziehe gegebenenfalls einen verlässlichen Freelancer dazu. Aber du bleibst immer mein Ansprechpartner.

**F: Arbeitest du auch mit WordPress?**
A: Ja, wenn es zum Projekt passt. Ich bin nicht religiös bei Tech-Entscheidungen. Was zählt ist, dass das Endergebnis schnell, wartbar und sicher ist.

**F: Wie lange dauert ein Projekt?**
A: Eine Landing Page: 1–2 Wochen. Eine Business-Site: 3–5 Wochen. Custom Builds: 6 Wochen aufwärts. Du bekommst nach dem Erstgespräch einen konkreten Zeitplan.

**F: Was ist mit DSGVO und Rechtssicherheit?**
A: Standard. Alle Sites werden DSGVO-konform aufgesetzt — Cookie-Banner, Impressum, Datenschutzerklärung. Für AGB empfehle ich eine anwaltliche Prüfung; ich kann dir Vorlagen-Anbieter empfehlen.

**F: Wo läuft das Hosting?**
A: Standardmäßig auf Servern in Deutschland (Hetzner) oder bei Vercel mit EU-Region. Du entscheidest mit.

**F: Kann ich die Site später selbst pflegen?**
A: Ja. Wenn du ein CMS willst (Sanity oder WordPress), kannst du Inhalte selbst anpassen. Bei Custom Code dokumentiere ich alles so, dass auch andere Entwickler weiterarbeiten können.

**F: Was wenn ich später unzufrieden bin?**
A: Sag's mir. Direkt. Wir finden eine Lösung — entweder ich fixe es oder du bekommst dein Geld für den nicht erbrachten Teil zurück. Verträge regeln das im Detail.

## Anweisungen für Claude Code

Wenn du dieses Dokument in Claude Code übergibst:

1. **Plan Mode:** Lass Claude Code zuerst einen Plan erstellen, welche Sections in welcher Reihenfolge gebaut werden, basierend auf dem Design das du bereits hast.
2. **Mapping:** Sag Claude Code explizit, welche Section in welcher Komponente landet (z.B. "Section 2 = `Hero.tsx`, Section 3 = `Services.tsx`").
3. **Platzhalter:** Die `XXX €` Preise und ähnliche Stellen sind absichtliche Platzhalter — entscheide vorher selbst, was du einsetzen willst.
4. **Tonalität:** Wenn Claude Code Text generiert, der nicht in diesem Dokument steht (z.B. Error-States, Form-Validation-Messages), soll es sich an der Tonalität in Section 1 orientieren.
5. **Was NICHT auf die Seite gehört:** Keine erfundenen Kundenstimmen, keine Stock-Photos von "happy business people", keine Marketing-Buzzwords.
